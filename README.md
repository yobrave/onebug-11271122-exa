# The Excuse an AI Agent Gives Its Human

Agent-excuse one-liner entry, staged by main.py. Run the builder:

```sh
python main.py
```

It verifies `entry.txt` against the gate and copies it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, printing a JSON receipt.
